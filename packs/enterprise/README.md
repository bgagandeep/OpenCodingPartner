# Consult and enterprise packs

This directory reserves the name. It contains no code, no price, no account system, and no meter.

The OpenCodingPartner core is the mesh in this repository: session, System-1 route, manager plan, one coding worker. That core is free and open source under Apache-2.0. The operator owns Laya weights, chat-model credentials, and coding-runtime accounts.

A future pack, if the Board adds one, will live in its own document and will stay optional. Running `ocp` will not require it.
