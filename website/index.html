Built in

  • OCP Agent & OCP Coder

    Coding, QA, security, research, and computer teammates — optional external ACP binaries or the built-in runtime. No model ships in the box.

  • Plan, approve, audit

    Plan-before-write, Allow once / Always / Deny / Redirect, fail-closed when unattended. Routine approvals expire (10 minutes by default). Audit log stays on this machine.

  • Deny rules & routines

    Rules can name a tool, path, command prefix, and who they apply to. Shell calls are refused before they run. Routines pause after ten failures in a row; you can save a finished task as a routine.

  • Hand-offs & open work

    Hand off a finished task to another bot. The activity list shows waiting approvals, unsent drafts, open responsibilities, and routines — without exposing draft bodies or secrets.

  • Virtual computer

    Each bot can use its own display and browser profile. Live stream, mouse and keyboard, Take Control, then return responsibility to the bot.

  • Plugins tab (18 shipped)

    Install onto one bot — skills and HTTP MCP connectors, secrets in the vault. Penpot, Storybook, and Canva use your instance URL and token or app. Image generation calls your OpenAI-compatible endpoint and model; nothing default ships, and usage hits your meter. A checksum verifies the manifest at install; it does not constrain what a remote server does afterward.

  • Connect & drafts

    Slack, Telegram, and mail wait for a person to send. WhatsApp and Teams reach stay draft-only — allowing still sends nothing. BYO Google and Microsoft OAuth clients; tokens in the vault.

  • Memory, skills, themes

    Correct or forget workspace memory. Skills library, routines with cron and webhooks, Issue→PR, usage meter and cap. Studio themes: Dark (default glass), Light, and System from the header.

FAQ

Is the studio hosted?

No. The app binds to 127.0.0.1 by default. This site is marketing only; the product runs locally.

Which models work?

Any you configure — OpenRouter or an OpenAI-compatible base URL (Ollama, LM Studio, vLLM, custom).

Where is my data?

On your machine under the OCP data directory. Keys are not stored in task logs or state.json.

What are plugins?

Eighteen manifests ship in the catalog (product 0.2.0). On the Plugins tab you install skills and HTTP MCP connectors onto one bot. Penpot, Storybook, Canva, and image generation each need URLs, tokens, or apps you provide — there is no bundled image provider. Install checks a SHA-256 checksum on the manifest bytes; that proves integrity at install time, not that a remote MCP server will behave a certain way later. Not a hosted marketplace.

Do WhatsApp or Teams send messages?

No. Reach for WhatsApp and Teams writes a local draft or outbox. Allowing still sends nothing — same as documented in the product.

Voice or meetings?

Not in this product. There is no voice route or meeting surface in the studio.

Install

Node.js ≥ 22.14 · pnpm · optional Docker for isolation

git clone https://github.com/bgagandeep/OpenCodingPartner.git
cd OpenCodingPartner
corepack enable && corepack pnpm install && corepack pnpm build
export OPENROUTER_API_KEY="your-key"
corepack pnpm app
