FAQ

Is the studio hosted?

No. The app binds to 127.0.0.1 by default. This site is marketing only; the product runs locally.

Which models work?

Any you configure — OpenRouter or an OpenAI-compatible base URL (Ollama, LM Studio, vLLM, custom).

Where is my data?

On your machine under the OCP data directory. Keys are not stored in task logs or state.json.

What are plugins?

Manifests you install onto one bot — bundled skills and HTTP MCP connectors, with secrets in the vault. Not a hosted store.

Install

Node.js ≥ 22.14 · pnpm · optional Docker for isolation

git clone https://github.com/bgagandeep/OpenCodingPartner.git
cd OpenCodingPartner
corepack enable && corepack pnpm install && corepack pnpm build
export OPENROUTER_API_KEY="your-key"
corepack pnpm app
open http://127.0.0.1:4317
