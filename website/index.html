What we ship

Decide, then act

Plans and consequential tools wait on Allow once, Deny, or Redirect. Unattended runs fail closed — we record every outcome on the audit page.

A computer per teammate

Isolated displays and browser profiles per bot. Take control for sign-in, return responsibility when you are done — already in the studio you clone today.

Your models, your meter

No model in the box. OpenRouter or any OpenAI-compatible endpoint, including local Ollama. Keys never land in task logs or state files.

Work with many teammates at once

We built the studio for a lead plus coding, QA, security, and computer roles in one workspace — with routines, skills, channel drafts, and an usage cap you control.

Roster-first studio

Scan the sidebar like a team directory — not a graveyard of old chats.

Memory

Per-workspace notes that survive the next task.

History recall

Search prior transcripts in the same repo.

Guarded tools

Bounded reads/writes with secret scanning.

Provider-neutral

No default model. Route through OpenRouter or any OpenAI-compatible server — including local Ollama and LM Studio.

Give each teammate a job

Same studio, different responsibilities — pick a role to see how OCP frames the work.

OCP Coder

Ships features end to end: reads the repo, writes a plan, waits for your approve, edits files, runs checks, and opens a PR-ready diff.

A computer you can share

Each teammate can drive an isolated display — browser, mouse, keyboard — while you watch a live stream, click to take control, then return responsibility.

  • 1280×800 virtual desktop per workspace
  • Human takeover without stopping the studio
  • Isolated browser profiles between bots on Linux

What it costs

The core is free and open source. You pay only the model providers you choose — same as bringing your own keys to any serious agent stack.

Get Open Coding Partner

Requires Node.js ≥ 22.14 and pnpm. Docker optional for container isolation.

Quick install 
git clone https://github.com/bgagandeep/OpenCodingPartner.git
cd OpenCodingPartner
corepack enable && corepack pnpm install && corepack pnpm build
export OPENROUTER_API_KEY="your-key"
corepack pnpm app
