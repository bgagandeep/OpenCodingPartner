Coding teammates that stay with the work.

Open Coding Partner (OCP) is a provider-neutral studio for persistent AI teammates — not disposable chat threads. Each teammate keeps context, earns your trust through explicit approvals, and can operate a real virtual computer while you watch or take control.

Built for teammates, not sessions.

Leading agent products converged on the same insight: people do not want another chat history — they want colleagues who remember the repo, show presence, and finish multi-step work. OCP names that object plainly: a teammate with identity, memory, tools, and optional specialist handoffs.

Roster-first

Scan who is working, waiting, or blocked — the same peripheral clarity persistent-agent interfaces optimize for — without hiding the underlying workspace.

Plan before code

Consequential edits wait on an explicit approve step. QA and security reviewers can inspect diffs mechanically while you retain intent and risk decisions.

Computer you can share

Each workspace can drive an isolated display, browser, and input stream. Watch live, click to take control, then return responsibility to the teammate.

Everything serious builders asked for — on your terms.

  • OCP Agent & OCP Coder runtimes with optional external ACP binaries or the built-in native runtime.
  • OpenRouter or any OpenAI-compatible endpoint — Ollama, LM Studio, vLLM, or a custom base URL.
  • Guarded workspace tools — bounded reads/writes, memory, history recall, progressive tool discovery.
  • Virtual Computer Desktop — screen, mouse, keyboard, and browser control with human takeover.
  • Specialist review handoffs — pair coding teammates with QA or security reviewers in the same workspace.

Run the studio on your machine.

The dashboard binds to loopback only. Export a provider key, install with pnpm, and open the local studio.

git clone https://github.com/bgagandeep/OpenCodingPartner.git
cd OpenCodingPartner
corepack enable && corepack pnpm install && corepack pnpm build
export OPENROUTER_API_KEY="your-key"
corepack pnpm app
# open http://127.0.0.1:4317

Requires Node.js ≥ 22.14. Docker is optional for container isolation. See README for platform-specific computer desktop setup.
